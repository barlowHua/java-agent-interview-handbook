# 32｜算法与现场编码：从不变量到可运行解法

> P0。面试不会因为工作年限长而自动免除编码。目标是读懂约束、说出正确性理由、写出可测试的 Java。先学 [14 算法主干](14-algorithms.md)，再用本章组织题型；[实验04](../labs/04-coding.md)提供可运行答案。本章不把特定题单当作全部可能考题。

## L1｜题型地图与复杂度

| 结构/方法 | 识别线索 | 必须解释的条件 | 代表练习 |
|---|---|---|---|
| 哈希、前缀和 | 相等关系、区间和 | 空前缀、重复、溢出 | 两数和、和为 K 子数组 |
| 双指针/滑动窗口 | 连续区间、单调可收缩 | 负数是否破坏单调性 | 最长无重复、最小覆盖 |
| 二分 | 有序或答案可行性单调 | 区间定义与端点更新 | lower_bound、最小处理速度 |
| 栈/单调栈 | 配对、最近更大/小 | 相等元素如何处理 | 有效括号、每日温度 |
| 链表 | 局部指针关系 | 断链、成环、空表 | 反转、环入口、合并 |
| 树/图 | 层次、连通、依赖 | visited 时机、是否有环 | BFS、LCA、拓扑、并查集 |
| 堆/排序 | 全局顺序或动态极值 | 稳定性、比较器、空间 | Top K、合并 K 路、归并 |
| 回溯/DP/贪心 | 状态选择、重复子问题 | 状态含义/贪心交换证明 | 子集、背包、区间调度 |

复杂度既报时间也报额外空间；区分期望、均摊、最坏。哈希查找常用平均 O(1)，动态数组追加均摊 O(1)，递归栈也计入空间。输入若可达十亿，先分析读入与输出成本，不可能靠 O(n²) 微调解决。

## L3｜面试问答与解法推导

### Q1：现场编码的开场与收尾怎样做？

**参考回答：**先复述输入、输出、规模、重复值、空值、是否允许修改输入及字符语义；用一个小例子验证理解。给出朴素解及瓶颈，再选择数据结构，明确循环不变量或递推含义后编码。完成后手走正常、空、单元素、重复、极端边界，检查溢出、索引、递归深度和资源释放。最后报复杂度与不支持的条件。没有必要为了显得熟练跳过思考过程。

**追问：十分钟还写不完怎么办？**先交付正确可运行的核心版本与关键用例，坦率指出剩余优化；不要用无法解释的模板掩盖错误。

### Q2：快速排序、归并排序、堆排序如何比较？

**参考回答：**快速排序分区后递归，通常平均 O(n log n)，朴素选枢轴可退化 O(n²)，随机化或更稳健策略降低特定输入风险；典型实现不稳定。归并排序分治后线性合并，最坏 O(n log n)，数组实现通常需 O(n) 辅助空间，相等时先取左侧可保持稳定。堆排序建堆 O(n)，逐次弹出总 O(n log n)，额外空间可 O(1)，通常不稳定。选择要结合稳定性、缓存局部性和内存限制。

**追问：Java 的排序都用同一种算法吗？**不能这样概括；基本类型、对象类型、重载和版本可能不同。业务依赖 API 的排序语义，不把某版实现当规范。

### Q3：前缀和为什么能在线性时间统计和为 K 的子数组？

**参考回答：**令 `prefix[j]` 为前 j 个数和，区间 `[i,j)` 和等于 `prefix[j]-prefix[i]`。遍历当前前缀 p，已有前缀中值为 `p-k` 的次数就是以当前位置结尾的答案增量。先查询再加入 p，初始放入 `0→1` 表示空前缀，否则漏掉从首元素开始的区间。此法支持负数，不依赖窗口和单调性。时间期望 O(n)，空间 O(n)，和与计数用 long 防常见 int 溢出。

**追问：只存某前缀是否存在够吗？**不够；多个相同前缀对应不同起点，必须存频次。完整实现见 [CodingPatterns.java](../labs/CodingPatterns.java)。

### Q4：滑动窗口何时适用，何时会失效？

**参考回答：**窗口维护一段连续区间，右端扩展加入信息，左端按有效性或最优性条件收缩。最长无重复使用字符频次或最近位置；最小覆盖维护需求数量与已满足种类。必须证明端点单调移动不会丢掉最优解。例如只含非负数时可按和大小收缩，出现负数后移动左端可能让和变大，原证明失效。每个元素最多进出常数次才得到 O(n)，不能只看到两个指针就声称线性。

**追问：字符串按 char 就是按字符吗？**Java char 是 UTF-16 码元；题目若要求 Unicode 码点或用户感知字符，需要更换遍历与索引定义。

### Q5：二分答案与数组二分有什么共同点？

**参考回答：**共同点是一个单调判定函数。例如给定处理速度 v 能否在 T 内完成任务，若可行，更大速度通常仍可行，就可找最小可行 v。先给出一定包含答案的上下界，再实现不会溢出的判定，循环维护不可行/可行边界。复杂度为判定成本乘 log 搜索范围。没有单调性时不能使用二分；浮点二分还要定义误差与终止方式。

**追问：mid 怎么写？**对合法非负索引常用 `lo+(hi-lo)/2`；跨完整有符号数范围仍可能溢出，应使用更宽类型或严格证明范围。

### Q6：单调栈如何求“下一个更大元素”？

**参考回答：**栈里存尚未找到答案的索引，值维持单调。扫描新值 x，反复弹出栈顶中小于 x 的元素，它们的下一个更大值就是当前 x；再把当前索引入栈。每个元素只入栈、出栈一次，总 O(n)，空间 O(n)。相等值是否弹出取决于题目是严格大于还是大于等于，索引差用于求等待天数时不能只存值。

**追问：柱状图最大矩形怎么迁移？**找到每根柱子左右第一个更低边界，宽度由边界决定；用哨兵统一弹栈，并仔细处理等高柱子的边界归属。

### Q7：链表快慢指针为什么能找到环入口？

**参考回答：**有环时，快指针每步比慢指针多走一步，在环内的相对距离最终为环长的倍数而相遇。设头到入口距离 a，入口到相遇点 b，环长 c；相遇时路程关系给出 `a+b` 是 c 的整数倍。让一个指针回头部，另一个留在相遇点，两者同速前进，经过 a 步在入口相遇。实现时先验证 fast 与 fast.next 非空，没有相遇不能直接进入第二阶段。

**追问：只比较节点值可以吗？**不行；判断环和相遇要比较节点身份，不同节点可能值相同。算法空间 O(1)。

### Q8：树的递归题怎样避免只会套模板？

**参考回答：**把递归函数含义写成一句可测试契约，例如“返回以 node 为根的高度，同时发现不平衡时返回失败标记”。为空给基础值，从左右子问题组合当前结果，证明没有重复遍历。平衡树判断若每个节点重新算子树高度会退化 O(n²)，一次后序返回高度可 O(n)。递归空间取决于树高，退化链可 O(n)，超深输入要改显式栈。

**追问：最近公共祖先需要 BST 性质吗？**普通二叉树可后序汇总目标出现情况；BST 可用有序性缩小范围。还要明确两个目标是否保证存在。

### Q9：BFS 和 DFS 的 visited 应该何时设置？

**参考回答：**无权图 BFS 通常入队时标记，避免同一节点被不同父节点反复入队，队列层次保证首次到达的边数最小。DFS 一进入节点就标记，防止环递归。若任务是列举所有简单路径，visited 常表示当前路径，需要回溯撤销，而不是全局永久标记。算法复杂度通常按邻接表 O(V+E) 计算；递归 DFS 还需考虑栈深。

**追问：有权最短路也用普通 BFS 吗？**仅适用等权等条件；非负权通常用 Dijkstra，负权需选择满足条件的其他算法。

### Q10：拓扑排序如何判断依赖循环？

**参考回答：**Kahn 算法计算所有节点入度，把入度零节点入队；每次取出节点，删除其出边并将新入度零节点入队。最终处理数等于节点数则得到一个拓扑序；小于则剩余图含环。边语义必须约定，例如 `u→v` 表示 u 先于 v，重复边要么保留并一致计数，要么去重。孤立节点也要纳入。复杂度 O(V+E)。

**追问：如何输出具体环？**在剩余图或原图做带递归栈标记的 DFS，遇到指向当前路径的边后沿父节点重建；仅处理数不足无法直接给环路径。

### Q11：并查集解决什么，不能解决什么？

**参考回答：**并查集维护集合划分，find 查代表元，union 合并两个集合；路径压缩和按秩/大小合并可让一系列操作达到接近常数的均摊复杂度。适合无向连通性、冗余边、Kruskal 等。它不直接提供路径，不适合普通动态删边，也不能拿无向连通关系代替有向可达性。设计时维护组件数，只有两个根不同才减一。

**追问：为什么压缩路径不改变结果？**所有修改仅将节点连向同一集合的根，不改变集合成员；回滚并查集则需谨慎处理压缩带来的大量改动。

### Q12：Top K 是排序、堆还是快速选择？

**参考回答：**全排序 O(n log n) 简单且能输出完整顺序；维护大小 K 的小根堆处理最大 K 个元素，时间 O(n log K)、空间 O(K)，适合流式；快速选择通常期望 O(n)，但结果区域未排序，且最坏情况与枢轴策略有关。若题目是频次 Top K，先统计频次，n 与不同值数 m 要区分。相同分数如何决胜必须明确，比较器不能简单相减导致溢出。

**追问：海量数据放不下内存？**可分片统计或外部排序，局部候选合并的正确性要按“值 Top K”还是“全局频次 Top K”分别证明；后者不能随意丢弃每片低频项。

### Q13：合并 K 个有序流为什么用堆？

**参考回答：**把每个非空流的当前最小元素放入小根堆，弹出全局最小后只补入该流下一个值。堆始终代表每个流未输出部分的最小值，保证输出有序。总元素 N、流数 K，时间 O(N log K)，空间 O(K)，不能一次性把所有值读入内存再说流式。实际流需要处理结束、读取失败、背压和稳定排序的二级键。

**追问：某一路暂时没有数据怎么办？**若不能证明它未来值大于当前候选，就不能安全越过它；实时事件系统往往需要水位或允许迟到的语义。

### Q14：动态规划从哪里开始，而不是背公式？

**参考回答：**先定义状态代表的子问题和取值含义，再确定最后一步选择与转移，给出边界和依赖顺序。例如零钱最少个数 `dp[s]` 表示组成金额 s 的最少枚数，不可达用安全哨兵；`dp[0]=0`，从可达 `s-coin` 转移。要证明子问题覆盖所有合法方案且没有读取未定义状态。空间压缩改变遍历顺序可能改变“每件一次/无限次”的含义。

**追问：记忆化搜索等同 DP 吗？**它是自顶向下求解重叠子问题的一种方式；递归深度和状态访问稀疏性影响取舍。

### Q15：0/1 背包为什么容量要倒序遍历？

**参考回答：**二维状态用前 i 件物品处理容量 c；压缩为一维后，取当前物品需要上一轮的 `dp[c-weight]`。倒序让这个较小容量还未被当前物品更新，确保每件最多一次。正序会读到本轮已经使用当前物品的结果，变成可重复使用语义。初始值要区分“最多容量”与“恰好装满”，后者不可达状态不能全置零。

**追问：重量为零怎么办？**必须先定义题意；0/1 可处理一次但需谨慎实现，完全背包若零重正收益则最优值无界，不能照搬模板。

### Q16：LIS 与 LCS、编辑距离有什么区别？

**参考回答：**LIS 在单序列中找严格递增子序列，可用 O(n²) DP，或维护各长度最小结尾值加 lower_bound 得 O(n log n)；该数组不是最终子序列本身。LCS 比较两序列保持相对顺序的公共子序列。编辑距离用前缀长度作为二维状态，按插入、删除、替换转移，并定义各操作成本。LIS/LCS可以选择不连续位置形成子序列；编辑距离计算完整前缀/字符串之间的变换成本，不能免费跳过未匹配字符。

**追问：严格递增变非递减怎么改？**二分从第一个 `>=x` 改为第一个 `>x`，允许相等元素延长长度；必须与目标定义一致。

### Q17：回溯去重为什么不应只用结果 HashSet？

**参考回答：**回溯枚举选择树，明确路径、剩余候选与结束条件，退出分支时撤销状态。对含重复值的排列，排序后常在同层跳过重复候选，配合 used 防同一元素重复使用；不同层允许相同值来自不同位置。结果集合去重虽有时正确，但仍搜索大量重复分支且增加内存。剪枝必须证明被剪分支不可能产生新合法答案，不能凭直觉删掉。

**追问：为什么时间常是指数或阶乘？**输出本身可能这么多，算法无法比输出规模更快；可讨论额外开销和按需生成。

### Q18：贪心法如何证明，何时必须退回 DP？

**参考回答：**给出一个局部选择规则，然后用交换论证、领先性质或结构定理证明存在最优解包含该选择。无权区间调度按最早结束选择可留更多空间；改为带权收益最大时相同规则一般失效，需要按兼容前驱做 DP。能通过几个例子不等于正确，首先主动寻找反例。题目中有最优值也不意味着必须 DP，要看局部选择是否能被证明。

**追问：硬币找零总拿最大面额可以吗？**一般不行，例如面额 1、3、4 找 6，贪心得 4+1+1，最优是 3+3。

### Q19：区间题最容易错在哪里？

**参考回答：**先明确闭区间、开区间、半开区间；`[1,2]` 与 `[2,3]` 在闭区间语义相交，而半开预约 `[1,2)`、`[2,3)` 可以首尾相接。合并按起点排序后维护最后区间终点；最少会议室可用终点堆或扫描线，时间相等时先释放还是先占用由边界语义决定。比较器、空输入、负时间、原数组是否允许被修改都要约定。

**追问：扫描线事件同一时间如何排序？**半开预约先处理结束，避免把无重叠算成同时占用；闭区间则按题意调整。

### Q20：把算法写成生产组件还要补什么？

**参考回答：**算法正确仅是起点，还需输入规模限制、异常语义、线程安全、取消和超时、内存预算、可观测性以及 API 契约。例如 LRU 的 O(1) 操作不保证并发安全；缓存还涉及容量权重、过期、加载合并和命中统计。不要把面试题示例包装成生产库，应明确简化点，在真实需求下决定复用成熟实现还是自行维护。

**追问：如何验证一个复杂实现？**用小规模穷举或独立朴素算法做差分测试，加随机种子可复现；对关键不变量做断言，比测试另一个同样复杂的实现更可靠。
