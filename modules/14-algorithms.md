# 14｜算法、数据结构与现场编码

优先级：P0，贯穿全程。目标：从题目约束建立模型，写出可验证代码，而非记住题号。示例采用 Java 8 可编译语法，兼容较新 JDK；运行入口见 [可执行练习](../labs/04-coding.md)。

## L1 必会：先说清楚输入输出

现场编码先确认规模、重复值、负数、是否有序、是否允许修改输入、空值、整数溢出以及返回多个答案的规则。随后给朴素方案与复杂度，再利用约束优化。边写边解释不变量，比逐行读代码有价值。

平均复杂度和最坏复杂度要区分；哈希表操作通常按平均 O(1) 分析，不是所有实现与输入都恒定。空间复杂度要说明是否计入输出、递归栈与复制。

## L2 原理：十二种模式

| 模式 | 识别信号 | 核心不变量或状态 | 常见错误 |
| --- | --- | --- | --- |
| 哈希 | 配对、计数、去重 | 记录已扫描元素的信息 | 先插入当前元素导致错误复用 |
| 双指针 | 有序数组、原地处理 | 已处理区间满足要求 | 无条件移动两个指针 |
| 滑动窗口 | 连续子串/区间 | 当前窗口满足约束或可收缩 | 把仅适用正数的和窗口套到负数 |
| 二分 | 单调谓词、边界位置 | 左侧不满足，右侧满足 | 边界不收缩、mid 溢出 |
| 前缀和 | 多次区间求和、和计数 | prefix[j]-prefix[i] 表示区间 | 忘记初始 0 或整数溢出 |
| 栈/单调栈 | 括号、最近更大/更小 | 栈中候选保持指定顺序 | 重复值比较符不一致 |
| 堆 | Top K、流式最值、合并 | 堆顶是当前保留集的边界 | 大根/小根选择相反 |
| 链表 | 节点重连 | 保存未处理链，避免断链 | 改 next 后丢掉后继 |
| DFS/BFS | 连通性、树/图遍历 | 每点至多按规则访问 | 忘记 visited、递归栈溢出 |
| 回溯 | 枚举组合和排列 | 路径、选择集、撤销对称 | 结果保存同一可变列表 |
| 动态规划 | 重叠子问题与最优子结构 | 状态含义、转移、初值、遍历序 | 只背转移不定义状态 |
| 并查集 | 动态连通与分组 | 根代表集合、合并维护关系 | 误以为支持高效删除边 |

### 二分边界的推导

求第一个 `a[i] >= target` 的下标，使用 `[lo, hi)`，初值 `lo=0, hi=n`。保持 lo 左边均小于 target，hi 及右边均大于等于 target。若 `a[mid] < target`，排除 mid 及左侧，令 lo=mid+1；否则 hi=mid。区间每轮严格缩小，到 lo=hi 返回 lo，可能等于 n。重复值与空数组都自然覆盖。

### 动态规划的推导

最少硬币数：假设面额是正整数、每种无限使用、金额非负。定义 `dp[x]` 为凑出 x 的最少枚数，`dp[0]=0`；可从 x-c 的可达状态转移到 x。不可达需要独立哨兵，不能默认 0。外层金额递增使较小状态已算完。若问题改成“组合数”或“每枚只能用一次”，状态和遍历次序必须重新分析。

## L3 工程：从算法正确走到代码可靠

一段算法在刷题条件下正确，不代表可直接上线。LRU 还涉及并发、TTL、内存权重和缓存击穿；图遍历要考虑恶意深度和输入规模；计数器需要考虑 long 溢出；输入修改要在 API 契约里写明。

本项目提供 10 组可执行示例：lowerBound、twoSum、最长无重复子串、反转链表、合并区间、Top K、层序遍历、岛屿计数、最少硬币和 LRU。代码是参考答案；训练时先自己写，再用边界对照，不能只运行一次看“通过”。

## L4 拓展：根据约束重新选择

若数据不能全部装入内存，排序/哈希题可能需要外部排序、分桶或流式近似；若数据持续更新，静态预处理的收益要重新计算；若需要准确统计与近似统计，误差界和资源预算不同。不要未经讨论就用 Bloom Filter 代替精确集合。

## 核心面试题与追问

### Q1｜如何证明二分查找不会死循环？

**参考回答**：先明确区间含义和不变量。使用 `[lo, hi)` 时，每次 mid 位于区间内；若 mid 不满足条件，lo 变成 mid+1，否则 hi 变成 mid，两种情况都严格缩短 hi-lo。结束时 lo=hi，再由两边的不变量得到边界位置。不能在半开区间里随意混用 `hi=mid-1` 之类闭区间写法。

**追问：全部元素小于 target？** 返回 n，调用者必须检查是否越界；这不是没找到时随意返回 -1 的接口。

### Q2｜滑动窗口为什么不能解决所有子数组和问题？

**参考回答**：窗口算法依赖可维护的单调关系，例如正数数组中右扩会让和不减、左缩会让和不增。加入负数后这种关系不成立，和大于目标时收缩可能错过答案。若要统计和等于 k 的所有子数组，可以用前缀和频次，将区间和转为两个前缀的差。

**追问：为什么频次而不是 Set？** 多个前缀可能值相同，每个都对应不同起点，Set 会丢失合法区间数量。

### Q3｜Top K 为什么常用小根堆？

**参考回答**：要保留最大的 K 个元素，小根堆顶是已保留集合中最小的候选。新元素若更大，就替换堆顶；更小则忽略。这样堆大小限制在 K，每个元素处理 O(log K)。频次问题先计数，复杂度还要加统计和不同元素个数；K 接近 n 时排序可能更简单。

**追问：相同频次怎么返回？** 先确认是否要求稳定顺序；如果要求，比较器和最终排序应明确次级规则。

### Q4｜BFS 与 DFS 怎么选？

**参考回答**：两者都能遍历连通结构。无权图最少边数路径适合 BFS，因为按层扩展；DFS 适合递归结构、回溯和某些拓扑分析。两者都需处理重复访问。DFS 深链可能栈溢出，BFS 宽层可能占用较大队列，要按结构和内存约束选。

**追问：有权最短路也能 BFS 吗？** 一般不能，需要根据边权条件考虑 Dijkstra、0-1 BFS 或其他算法。

### Q5｜动态规划写不出来时先做什么？

**参考回答**：先用小例子明确子问题和状态含义，再写递归关系、初始值、非法状态和计算顺序。检查每个状态是否包含做决策所需的信息，再分析重叠子问题。不要先背一个 dp 数组公式套题；金额、组合数、排列数和有限次数选择都可能需要不同顺序或状态。

**追问：怎样验证转移？** 对小规模输入穷举，与 DP 结果对照，并检查最小值、不可达和重复选择等边界。

### Q6｜现场代码写完后怎么自检？

**参考回答**：先跑最小例和正常例，再看空输入、单元素、重复、全部相同、极值和失败情形；对照循环不变量检查边界和更新顺序。说明是否修改输入、是否可能溢出和递归深度风险。最后重新计算复杂度，把排序、复制、输出和容器操作都算进去。

**追问：没有运行环境怎么办？** 用表格手推变量、指针与容器状态，选择能暴露边界错误的例子，不只走最顺的路径。
