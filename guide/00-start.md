# 从这里开始：怎样把这套内容学成自己的能力

适用对象：约 10 年开发经验，目标为资深 Java 后端或 Agent 应用工程岗位。版本：2026-10-04 扩充审校版。本文里的层级是学习深度，不映射任何公司的职级；优先级是本项目的学习安排，不是面试题出现频率的统计。

## 先明确成果

你最终要带进面试的，不是一串名词，而是五类可以展示的能力：能写正确代码；能解释关键机制；能设计有边界的系统；能从证据定位问题；能证明自己在项目中做出的判断。背会参考回答有助于建立表达框架，但换一个约束仍能推理、落地和验证，才算掌握。

这套资料是通用准备基线，不声称收录某家公司内部题库，也不能保证某次录用。具体轮次以目标岗位和招聘方信息为准。官方公开面试准备材料也强调知识应用、编码和系统设计，而非细节记忆；本项目据此覆盖这些能力，但不把一家公司的流程当作所有公司的规则。[Amazon 软件开发面试准备](https://amazon.jobs/content/en/how-we-hire/interview-prep/software-development-topics)

## 四层深度

| 层级 | 你要做到什么 | 判断方式 | 不算过关的表现 |
| --- | --- | --- | --- |
| L1 基础口述 | 定义、用途、主要边界说准确 | 不看资料讲 60～90 秒 | 只会念名词，概念互相混淆 |
| L2 原理解释 | 画出执行顺序，解释为什么 | 两轮“为什么”与一个反例 | 背源码行号但不懂机制 |
| L3 工程应用 | 在真实约束下落地、排障和验证 | 完成实验或分析证据 | 只说加缓存、加机器、重试 |
| L4 架构取舍 | 比较方案，量化代价与迁移风险 | 约束变化后修改方案 | 把技术复杂度当先进程度 |

十年经验的训练目标：所有 P0 达到 L2，主责领域达到 L3，至少两个真实项目能展示 L4 判断。广度模块可以先到 L1/L2；不要为了“全懂”而拖延自己的薄弱核心。Agent 岗的检索、工具执行、评测、安全边界要达到 L3。

## 三类优先级

- **P0 核心必修**：Java、集合、并发、JVM、Spring、MySQL、Redis、消息、分布式、网络、系统设计、可靠性、算法、项目表达。
- **P1 岗位增强**：安全与交付、LLM/RAG/Agent 工程。面试 Agent 岗时，15～18 与 26～28 章升级为 P0；安全中的鉴权、输入边界、测试隔离同样是所有岗位必须掌握的底线。
- **P2 拓宽视野**：各章 L4 中的专项，如共识证明、复杂 GC 细节、推理基础设施、深层检索优化。按 JD 和项目需要选择，不能挤掉编码与项目复盘。

每章同时包含必会知识、原理、工程场景、回答样例、追问、误区和练习。样例是表达参考，不是固定话术：条件不同时结论也会变。

## 一次 90 分钟的学习流程

1. **10 分钟闭卷回忆**：先回答上一节三个问题。答不出再看答案。
2. **25 分钟理解正文**：只学一个子主题，画机制图或写执行序列，标出前提。
3. **20 分钟口述追问**：先 90 秒回答，再连续回答两个“为什么/如果失败怎么办”。录音或写出逐字稿。
4. **25 分钟编码或证据**：跑一个实验、手写一道题、分析一份执行计划或故障日志。
5. **10 分钟复盘**：记录一个误区、一条证据、一个未解决问题，安排下一次回忆。

只有 45 分钟时，保留“闭卷回忆 + 一个概念 + 一个练习”。周末另做系统设计。不要用抄笔记替代检索式回忆。

## 复习间隔与状态

建议学后第 1、3、7、14、30 天回忆，这是可调整的安排，不是记忆效果保证。离线阅读器的卡片以每次复习结果决定下一间隔；“记不住”回到较短间隔。章节状态和卡片熟练度分开：卡片记得好不等于实验完成。

章节使用五种状态：未开始、已读、能口述、已实践、通过模拟。浏览器本地保存状态与笔记；换浏览器或清理存储前，导出进度 JSON。建议每周备份到自己选择的位置。

## 推荐的第一天

- 花 20 分钟完成 [入学诊断](02-assessment.md)，先不看参考锚点。
- 在 [项目与面试表达](../modules/19-project-interview.md) 写出一个真实项目的 5 分钟介绍。
- 闭卷完成算法“二分查找”的边界讨论，不会写也如实记录。
- 按 [学习路线](01-roadmap.md) 选择 Java 主线或 Java + Agent 主线，今天只补一个最低分的 P0 模块。

## 如何继续让 AI 当面试官

把下面的指令发在这个项目的会话中：

> 按本项目第 03 章并发模块面试我。一次一道问题，先听我的回答再追问两轮，不要提前给参考答案。完成后分别评价准确性、原理、边界、表达和实践证据；将错误整理成待复习项。不要替我编造项目数据。

学习时可以说“用例子解释这一节”；考试时明确“闭卷”。面试官应先追问你的推理，再展示参考答案。没有真实做过的实践可以作为练习项目介绍，但不能说成生产经历。
